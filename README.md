# Alex Rafanomezantsoa Portfolio

A minimal, editorial personal portfolio built with Astro.

Reusable controls use shadcn/ui with Tailwind CSS and Astro's React integration,
rendered at build time without client hydration. See [UI components](docs/UI_COMPONENTS.md)
for component usage, styling decisions and validation commands.

## Positioning

**Multidisciplinary Designer & Developer**

The site showcases selected work across:

- editorial design;
- art direction;
- branding;
- web;
- product;
- 2D/3D;
- creative technology.

## Development

Commands will be finalized by the bootstrap task.

Expected pattern:

```bash
npm install
npm run dev
npm run check
npm run build
npm run preview
```

Use the actual package manager selected during bootstrap.
