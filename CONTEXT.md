# Project Context

## Project

Personal portfolio for Alex Mezan.

## Positioning

Alex is presented as a multidisciplinary creative professional working at the intersection of:

- graphic design;
- editorial design;
- art direction;
- web design;
- frontend/product development;
- digital communication;
- 2D/3D visualization;
- creative technology;
- AI-assisted creative workflows.

The portfolio should avoid reducing the profile to only "graphic designer" or only "developer".

Recommended public positioning:

> Multidisciplinary Designer & Developer.

Secondary descriptor:

> Designing identities, editorial experiences, digital products and visual systems.

## Geographic context

Professional base:

- Nosy Be, Madagascar.

This can be displayed publicly as location context. Do not expose private address or other private location information.

## Representative project families

Initial portfolio content can be organized around:

1. Le Journal — editorial design / art direction / digital publishing.
2. Le Zahir — hospitality / branding / communication / web.
3. Web & Digital — selected websites and digital experiences.
4. Nosyra — product / SaaS / interface / development.
5. 3D & Architecture — 2D/3D visualization and spatial work.
6. Malagasy NLP / Lab — Python / language tools / open source experiments.
7. Excel Analytics Tool — product / data / UX experiment.
8. AI Visual Experiments — creative technology / image workflows.

Only publish projects for which real assets and accurate descriptions are available.

## Visual direction

Target mix:

- 70% Minimal Swiss / International Typographic Style influence
- 20% Creative Developer
- 10% Editorial Magazine

The site is not a literal historical Swiss-design reproduction. The influence should appear through grid, typography, restraint, hierarchy, and spacing.

## Desired impression

Within five seconds, a visitor should understand:

1. who Alex is;
2. that he works across design and development;
3. that the portfolio contains real visual work;
4. where to view projects;
5. how to contact him.

## Audience

Primary:

- creative agencies;
- hospitality and tourism brands;
- design studios;
- digital/product teams;
- potential collaborators;
- prospective clients.

Secondary:

- developers;
- open-source collaborators;
- recruiters;
- editorial partners.

## Tone

- confident;
- concise;
- professional;
- contemporary;
- not corporate;
- not over-explained;
- no empty superlatives.

## Content language

The architecture must be i18n-ready, but multilingual support is not part of the initial implementation unless explicitly requested.

Do not hard-code assumptions that would make future EN / FR / IT support difficult.

## Privacy rule

The site should contain professional information only.

Do not publish:

- private family information;
- salary information;
- private phone numbers unless explicitly approved;
- home address;
- private credentials;
- unpublished client data.
